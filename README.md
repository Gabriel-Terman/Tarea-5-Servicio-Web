# Servicio Web de Contactos con Express.js

## Descripción

Este proyecto consiste en un servicio web desarrollado con Node.js y Express.js que permite realizar las operaciones básicas de:

- Listar contactos.
- Almacenar contactos.

El servicio utiliza como fuente de datos la API proporcionada por:

http://www.raydelto.org/agenda.php

## Tecnologías Utilizadas

- Node.js
- Express.js
- Axios
- Cors
